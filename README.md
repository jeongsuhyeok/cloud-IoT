# claude-IoT
클라우드IOT서비스 (3222-001) 8팀

본 실습은 실제 Raspberry Pi 및 센서 장비가 없는 환경에서 수행보다 IoT에 대한 이해도를 끌어올리기 위함으로
따라서 GPIO 제어 및 센서 데이터 수집은 난수 기반으로 대체하여 구현하였다.

이를 통해 실제 하드웨어 제어는 포함되지 않았지만 IoT 시스템의 전체 데이터 흐름을 이해하는 데 목적을 두고 실습 코드를 작성해보았다.

c-1
    - GPIO 동작을 소프트웨어적으로 모방
	- 난수를 활용하여 센서 데이터(온도, 습도) 생성
	- CSV 파일로 데이터 저장

    ->IoT 디바이스(해당 과제에서는 실제 하드웨어가 존재하지 않아서 난수로 대체)에서 데이터가 생성되는 과정을 이해할 수 있다.

c-2
    - MQTT 프로토콜을 이용한 Pub/Sub 구조 구현
    - Publisher → Broker → Subscriber 흐름 구성
	- JSON 형식으로 데이터 송수신
	- Subscriber에서 데이터 출력 및 SQLite 저장

    -> IoT 환경에서의 데이터 통신 구조(MQTT를 이용한) 이해할 수 있다.

c-3
    - 생성된 데이터를 pandas로 분석
	- matplotlib을 이용한 시계열 그래프 시각화

    -> IoT 데이터를 활용한 분석 및 서비스 확장 가능성 이해할 수 있다.
